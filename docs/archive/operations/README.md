# Preserved operational fragments

`legacy_download_status.txt` is the exact 81-byte file previously named `0` at
the project root. It contains a September 12 FTP download progress line. The
audit found no maintained reference to that filename. Its content is preserved
here and in the checksummed pre-refactor backup; it is not a research result.

Root log shortcuts and `download_logs/` remain in place because historical
commands still refer to those locations. They are not automatically deleted.
