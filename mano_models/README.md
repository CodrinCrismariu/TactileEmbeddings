# Installed EgoPressure UV meshes

`MANO_UV_left.obj` and `MANO_UV_right.obj` are installed here. Refresh the viewer
and select EgoPressure; it defaults to the 3D hand surface. MANO pickle files are
not needed because the dataset supplies each recorded hand pose.

Source: [the public EgoForce author release](https://huggingface.co/chris10/EgoForce/tree/5a57b4026babc5b35cb53627c2e1c709e1276b65/_DATA/mano),
revision `5a57b4026babc5b35cb53627c2e1c709e1276b65`. These assets retain the MANO
non-commercial research license. Download provenance, checksums and the upstream
notice are in `processing/audits/egopressure_surface_view_v2/`.

Each mesh has 778 vertices, 1,538 triangles and 891 UV coordinates. The installed
files are intentionally ignored by version control. **Check hand models** can
re-detect them without restarting the viewer.

See [the viewer guide](../docs/EGOPRESSURE_VISUALIZATION.md).
